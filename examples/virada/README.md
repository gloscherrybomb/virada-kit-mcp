# Example: the Virada jersey

`reference.png` (a product picture, front three-quarter from the rider's left) made into a kit with layers only:
`kit.json` (written by `make_kit.py`, which builds the V mark from two shapes), exported as `virada.kit.zip`.
`compare.png`: the reference beside the kit on the game's rider (three-quarter and straight front), the check the
agent repeats until they match. `in_game.jpg`: the kit in the game. The back was not in the reference; it is listed
under `provenance.invented`.
